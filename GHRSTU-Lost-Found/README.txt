GHRSTU FIND — UPDATED PROJECT
==============================

This version keeps your existing SQLite database and uploaded photo.

Included upgrades:
- Live submitted reports on Home
- Explore/search/filter page
- Report detail page
- Uploaded photos displayed from the uploads folder
- Dynamic live stats
- Success/error toast messages
- Better Lost/Found routing
- Unique filenames for new uploads
- Drag & drop image upload
- Responsive Gen-Z glass/neon UI polish

RUN:
1. Open this project folder in VS Code.
2. Activate your existing environment.
3. Run: python app.py
4. Open: http://127.0.0.1:5000

Do not delete ghrstu_find.db or uploads/.
